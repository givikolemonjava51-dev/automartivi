# ავტომარტივი · დიზაინ ბორდი

გუნდის საზიარო დაფა: თასქები სამ სვეტად (მზადდება → მზადაა → დაიდო), დიზაინების ატვირთვა ორიგინალი ხარისხით, კომენტარები, ჩატი დიზაინერთან, ავტო ნიუსები და „წლების წინ ამ დღეს“.

## როგორ მუშაობს

- **ფრონტი:** სტატიკური HTML/CSS/JS (`index.html`, `style.css`, `app.css`, `app.js`), Vercel-ზე ჰოსტინგით. ბილდი არ სჭირდება.
- **ბექენდი:** Supabase პროექტი `automartivi` (`config.js`-ში URL და publishable key).
  - ცხრილები: `tasks`, `comments`, `designs`, `chat`, `news`, `history`, `meta`, `profiles`, `members`.
  - წვდომა მხოლოდ `members` სიაში მყოფ ელფოსტებს აქვს (row-level security).
  - ფაილები ინახება კერძო `designs` bucket-ში ბაიტ-ბაიტ, შეკუმშვის გარეშე (50 MB-მდე ფაილზე).
- **ნიუსები:** დაგეგმილი ამოცანა დღეში 3-ჯერ ავსებს `news` და `history` ცხრილებს.

## გუნდში ადამიანის დამატება

ადმინი (მარჯვენა ზედა წრე → „გუნდი“) ამატებს ელფოსტას. ამის შემდეგ ადამიანი საიტზე იმავე ელფოსტით რეგისტრირდება.
